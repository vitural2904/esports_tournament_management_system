# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Needs reporter input |
| ready-for-agent | ready-for-agent | Ready for agent work |
| ready-for-human | ready-for-human | Needs human work |
| wontfix | wontfix | Will not be actioned |

Use these labels when a skill names a triage role.
